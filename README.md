# Численное решение УЧП

Учебное настольное приложение на Python: классификация уравнений второго порядка,
теплопроводность, колебания закреплённой струны и стационарная температура пластины.
Интерфейс — Tkinter/ttk в стиле Windows 95; графики Matplotlib встроены в окно.
NumPy используется для массивов, метод прогонки реализован без SciPy.
Уравнения, производные, дроби, индексы и математические подписи набираются
Matplotlib MathText со шрифтом Computer Modern, как в LaTeX.
Отдельная установка LaTeX не нужна. Мелкие числа выводятся с показателем степени,
например 1 × 10⁻⁶ вместо технического `1e-06`.

## Запуск

Нужен Python 3.11+ с поддержкой Tkinter. Проверенная среда: Python 3.13.14,
Tk 9.0, NumPy 2.5.2, Matplotlib 3.11.1.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows вместо команды активации: `.venv\Scripts\activate`.
Проверка Tk: `python -m tkinter`. Если модуль `_tkinter` отсутствует, установите
сборку Python с Tk; в Linux обычно нужен системный пакет `python3-tk`.

## Возможности

- **Классификация:** коэффициенты A, B, C, дискриминант Δ = B² − 4AC, тип и пример.
- **Теплопроводность:** явная, неявная и схема Кранка—Николсона; параметры a, T, h, tau;
  численное и точное решения, максимальная ошибка выбранного временного слоя.
- **Сравнение трёх схем:** один график, общая сетка, ошибки каждого метода.
  Для сравнения сетка должна удовлетворять условию устойчивости явной схемы.
- **Исследование ошибки:** три сетки с h/2 и tau/4 на каждом уровне, таблица и график.
  Это совместное сгущение пространства и времени, а не отдельное определение их порядков.
- **Струна:** скорость c, длина L, амплитуда A, сетка; сравнение с точной формулой.
- **Лаплас:** температуры четырёх сторон единичного квадрата, метод Гаусса—Зейделя,
  допуск невязки и предел итераций, тепловая карта.

Ползунок под графиком выбирает временной слой. Панель Matplotlib позволяет
масштабировать, перемещать и сохранять график. В числах можно использовать точку или запятую.
При ошибке ввода предыдущий результат расчёта очищается.

### Быстрая проверка

1. На вкладке классификации A=1, B=0, C=1 → Δ=−4, эллиптический тип.
2. Теплопроводность: a=0.1, T=0.2, h=0.25, tau=0.1 → r=0.16;
   на последнем слое `[0, 0.4624, 0, −0.4624, 0]`, ошибка около 0.00836.
3. С теми же шагами a=1 → сообщение о неустойчивости явной схемы.
   Неявная схема и Кранк—Николсон допускают r>0.5.
4. Кнопка сравнения при исходных параметрах показывает три схемы и точное решение.
5. Струна: c=1, L=1, A=1, T=1, h=0.05, tau=0.05 → профиль в конце равен
   `−sin(πx)` с точностью машинного округления в узлах.
6. Лаплас: все температуры 42 → постоянное поле 42, невязка 0 за одну итерацию.

## Математические модели

Формулы и алгоритмы подробно разобраны в [METHODS.md](METHODS.md).

| Задача | Уравнение и условия | Метод |
| --- | --- | --- |
| Теплопроводность | u_t=a·u_xx, x∈[0,1], нулевые границы, u(x,0)=sin(2πx) | θ-схема: θ=0, 1, 1/2 |
| Струна | u_tt=c²·u_xx, x∈[0,L], нулевые границы, u(x,0)=A·sin(πx/L), u_t(x,0)=0 | Центральные разности, специальный первый слой |
| Лаплас | u_xx+u_yy=0 на [0,1]², постоянные температуры сторон | Гаусс—Зейдель |

Это фиксированные модельные задачи. Полей для произвольных формул нет.
Шаг h обязан делить длину, tau — конечное время T; приложение не меняет шаги молча.
Для задач с временем нужны минимум четыре пространственных интервала; для Лапласа — два.
Массивы ограничены 2 000 000 элементов. Для Лапласа также ограничено
произведение числа внутренних узлов на предел итераций: 20 000 000 обновлений.
Расчёты синхронные; на больших допустимых сетках окно может кратковременно ждать расчёта.

У Лапласа в углах берётся среднее двух смежных температур. Если температуры
соседних сторон различаются, угловые данные разрывны; невязка проверяется
во внутренних узлах. Она характеризует решение дискретной системы, а не ошибку
относительно непрерывного решения.
Неявная схема и Кранк—Николсон устойчивы без ограничения r≤0.5, но крупный шаг
ухудшает точность; у Кранка—Николсона возможны затухающие колебания.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют контрольные слои, дискретную синусоидальную моду для всех трёх схем,
сходимость, прогонку против независимого плотного решателя NumPy, точное распространение
струны при CFL=1, границы, симметрию, суперпозицию и невязку Лапласа,
ошибочные параметры и ограничения сетки. GitHub Actions запускает численные тесты.

Отдельная проверка интерфейса требует графического сеанса и открывает окна:

```sh
PDE_GUI_TESTS=1 python -m unittest discover -s tests -p 'test_gui.py' -v
```

- `tests/` — численные тесты и дополнительная проверка GUI.
- `grid_demo.py` — сохранённый учебный эксперимент с сеткой.
- `CONTEXT.md` — история и исходные требования учебного проекта.
