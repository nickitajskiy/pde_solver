## Математика текущей задачи

Решаем фиксированную модельную задачу, а не произвольное УЧП:

`u_t = a*u_xx`, `a > 0`, `0 <= x <= 1`, `0 <= t <= T`.

Границы: `u(0,t)=u(1,t)=0`. Начальное условие: `u(x,0)=sin(2*pi*x)`.

Точное решение: `U(x,t)=exp(-4*pi**2*a*t)*sin(2*pi*x)`.

Параметры: a — физический коэффициент; T — конец временной области; h/tau — шаги численной сетки. Аналитическое решение служит независимым эталоном, численный решатель не использует его для продвижения по времени.

Сетка: `x_i=i*h`, `t_n=n*tau`. Массив `u[n,i]`: строки — время, столбцы — координата. Интервалов на один меньше, чем узлов. `u[0,:]` — начальное условие; `u[:,0]` и `u[:,-1]` — границы.

Аппроксимации: `u_t ≈ (u_i^(n+1)-u_i^n)/tau`; `u_xx ≈ (u_(i+1)^n-2*u_i^n+u_(i-1)^n)/h**2`.

Явная схема:

`r=a*tau/h**2`

`u[n+1,i]=u[n,i]+r*(u[n,i+1]-2*u[n,i]+u[n,i-1])`

Устойчивость: `r <= 0.5`. Внешний цикл `range(number_t_points-1)`, внутренний `range(1,number_x_points-1)`.

Ошибка на выбранном временном слое: `max(abs(numerical-exact))`. Это максимум только по узлам пространства в данном времени, а не по всему непрерывному решению.

## Текущие функции

- `classify_pde(coef_a, coef_b, coef_c)` возвращает `(discriminant, pde_type)`.
- `exact_heat_solution(x, time, a)` возвращает значения точной формулы; np.asarray, проверки конечности, time>=0, a>0.
- `calculate_max_error(...)` проверяет одинаковую форму, непустоту и конечность; возвращает float максимума модулей разностей.
- `solve_heat_explicit(a, final_time, h, tau)` возвращает `(x,t,u,r)`.

Численный решатель проверяет конечность и положительность параметров, делимость области на шаги через round и np.isclose, устойчивость и лимит 2_000_000 элементов. Сетки через np.linspace. Текущая политика: h должен делить 1, tau должен делить T; молча менять шаги нельзя.

У классификации формула `Delta=B**2-4*A*C`, поскольку смешанный член записан как B*u_xy, а не 2B*u_xy. Delta<0 — эллиптический, =0 — параболический, >0 — гиперболический. Все коэффициенты нулевые — ValueError.

Внимание для будущей ревизии: текущий абсолютный tolerance=1e-12 в классификации зависит от масштаба коэффициентов; не считать его универсально корректным. Также позже проверить обработку nan/inf в классификации, минимальное число узлов и экстремально малые параметры решателя. Не отвлекать текущий учебный шаг массовым рефакторингом.
